How to estimate your score

  • Confirm the exact booklet code or set printed on the question paper.
  • Compare all 80 responses with the matching provisional key.
  • The published exam pattern is 80 questions for 100 marks, with 1.25 marks for each correct answer and no negative marking. Confirm details against the official prospectus.
  • Keep the result as an estimate until NVS publishes the official result.

Official updates

For official admission notices, results and instructions, visit Navodaya Vidyalaya Samiti (NVS). Unofficial answer keys are useful for practice and estimation only; the official NVS process is authoritative.

For parents: If a question appears disputed, compare the exact question and its options across the booklet, rather than relying only on a numbered answer list. TASVIA Academy will revise this resource if reliable official material becomes available.
